Built with Vite, React, TypeScript and Tailwind CSS. Created by
[Applace](https://github.com/cycle-inc/Applace), and an ordinary repository
regardless: nothing here depends on Applace being installed.

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run lint
npm run build      # -> dist/
```

Environment variables are read from `.env` and must be prefixed `VITE_` to reach
the browser. `.env` is not committed.
